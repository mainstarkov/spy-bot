# 🕵️ Шпион — Telegram-бот

Учебный проект на Python 3.10+, aiogram 3 и SQLite. Комнаты для 3–12 человек, два режима, один шпион, 15 локаций. Все действия проходят в личном чате с ботом.

## Запуск

1. Создайте бота через @BotFather командой /newbot и получите токен.
2. Откройте терминал в папке проекта:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
read -s BOT_TOKEN
export BOT_TOKEN
python bot.py
```

После `read -s BOT_TOKEN` вставьте токен и нажмите Enter. Ввод скрыт. Токен — пароль к боту: не публикуйте его, не добавляйте в отчёт или репозиторий. Остановка: Ctrl+C. Запускайте только один экземпляр бота с этим токеном и базой.

## Как играть — кнопками

1. Каждый участник открывает бота и нажимает «Старт».
2. Создатель выбирает «Создать онлайн» или «Создать в кабинете» и пересылает друзьям ссылку из сообщения комнаты.
3. Друзья открывают ссылку и нажимают «Старт». Также можно нажать «Войти по коду» и отправить код одним сообщением. Ввод можно отменить кнопкой «Отмена».
4. Когда соберутся 3–12 игроков, создатель нажимает «Начать игру». Каждый получает свою роль. Её можно снова посмотреть кнопкой «Моя роль».
5. Онлайн: пишите вопросы и ответы боту — он передаст текст всем участникам с именем автора. В кабинете: обсуждайте вслух.
6. Через 5 минут начинается голосование. Создатель может нажать «Начать голосование» раньше. Выберите имя подозреваемого под сообщением. Себя выбрать нельзя. Если потеряли сообщение, нажмите «Моя комната» — появятся кнопки голосования.
7. Голосование длится минуту или до ответа всех игроков. Единственный лидер, оказавшийся шпионом, означает победу мирных. При ничьей или ошибке побеждает шпион.
8. Только шпион видит кнопку «Угадать локацию». Она открывает список: выбор локации — окончательная единственная попытка. Правильный ответ даёт победу шпиону, ошибка — мирным.
9. После результата создатель нажимает «Новый раунд». Между раундами доступен «Выход из комнаты». Создателю во время раунда доступна кнопка «Остановить раунд».

Кнопки показываются под полем ввода и меняются в зависимости от этапа и роли. Если Telegram спрятал клавиатуру, нажмите значок клавиатуры рядом с полем ввода. «Моя комната» показывает состав и следующий шаг; «Как играть» объясняет правила. После обновления бота отправьте `/start`, чтобы получить новые кнопки.

Не показывайте другим экран со своей ролью. В онлайн-режиме указывайте имя того, кому задаёте вопрос. Передача голосовых, фото и видео пока не поддерживается. Команды предыдущей версии сохранены для совместимости.

## Игра в группе Telegram

Добавьте бота в группу и отправьте `/spy`. Бот опубликует кнопку входа. Каждый игрок открывает личку через кнопку и нажимает «Старт». Создатель запускает раунд там же. Обсуждайте в группе. Бот объявит этапы и результат в группе, а роли и кнопки для тайного голосования пришлёт в личку.

## Устройство проекта

- `game.py` — правила, комнаты, роли, голоса и сохранение SQLite.
- `bot.py` — команды, кнопки, сообщения, раздача ролей и таймеры.
- `test_game.py` — проверки правил и сохранения без Telegram.
- `spy.sqlite3` — создаётся рядом с программой при запуске. Содержит Telegram ID, имена и текущее состояние комнат; тексты обсуждения бот в базе не сохраняет. Роли активного раунда есть в базе: не раздавайте файл участникам.

Комнаты и время окончания этапа сохраняются после перезапуска. Просроченное обсуждение переходит в голосование при запуске. Завершённый раунд возвращает комнату в ожидание. Пустые комнаты удаляются. Рейтинг и история раундов не ведутся.

## Проверка

```sh
python -m unittest -v
```

Перед демонстрацией проверьте тремя Telegram-аккаунтами оба режима, блокировку бота одним игроком, голосование и перезапуск. Локальные тесты не проверяют доставку Telegram.
