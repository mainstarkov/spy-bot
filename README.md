# 🕵️ Шпион — Telegram-бот

[Играть в Telegram — @truespyrobot](https://t.me/truespyrobot)

Учебный проект на Python 3.10+, aiogram 3 и SQLite. Комнаты для 3–12 человек, два режима, один шпион, 15 локаций. Все действия проходят в личном чате с ботом.

## Запуск

1. Создайте бота через @BotFather командой /newbot и получите токен.
2. Откройте терминал в папке проекта:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
read -s BOT_TOKEN
export BOT_TOKEN
python bot.py
```

После `read -s BOT_TOKEN` вставьте токен и нажмите Enter. Ввод скрыт. Токен — пароль к боту: не публикуйте его, не добавляйте в отчёт или репозиторий. Остановка: Ctrl+C. Запускайте только один экземпляр бота с этим токеном и базой.

## Как играть в приватной группе Telegram

1. Создайте приватную группу в Telegram. В личке с ботом нажмите «Играть в группе» → «Добавить „Шпиона“ в группу» и выберите её. Если набор не запустился автоматически, отправьте `/spy` в группе.
2. Создатель проходит короткую проверку. Все участники, включая создателя, нажимают «Войти в игру» и открывают личку. Там будут секретные карточки и голоса.
3. Когда соберутся 3–12 человек, создатель нажимает «Начать игру» в группе. У каждого 90 секунд, чтобы выбрать карточку в личке. После отсчёта 3–2–1 бот удаляет секретные карточки.
4. Обсуждайте в группе по очереди. Ответьте на сообщение бота с ходом либо отправьте `/q вопрос` или `/a ответ`. Шпион может попробовать угадать локацию в личке.
5. Через 5 минут бот открывает тайное голосование на 60 секунд. Кнопки с именами приходят в личку. Если единственным лидером голосования стал шпион, побеждают мирные. Иначе побеждает шпион.
6. Итог и кнопка «Новый раунд» появятся в группе. При запуске следующего раунда бот убирает свои недавние игровые сообщения. Переписка игроков и итоги остаются.

## Устройство проекта

- `game.py` — правила, комнаты, роли, голоса и сохранение SQLite.
- `bot.py` — команды, кнопки, сообщения, раздача ролей и таймеры.
- `test_game.py` — проверки правил и сохранения без Telegram.
- `spy.sqlite3` — создаётся рядом с программой при запуске. Содержит Telegram ID, имена и текущее состояние комнат; тексты обсуждения бот в базе не сохраняет. Роли активного раунда есть в базе: не раздавайте файл участникам.

Комнаты и время окончания этапа сохраняются после перезапуска. Просроченное обсуждение переходит в голосование при запуске. Завершённый раунд возвращает комнату в ожидание. Пустые комнаты удаляются. Рейтинг и история раундов не ведутся.

## Проверка

```sh
python -m unittest -v
```

Перед демонстрацией проверьте тремя Telegram-аккаунтами оба режима, блокировку бота одним игроком, голосование и перезапуск. Локальные тесты не проверяют доставку Telegram.
