# 🕵️ Шпион для Telegram

Игра на Go для 3–12 человек в приватной группе Telegram. У всех, кроме шпиона, одна секретная локация. Мирные пытаются вычислить шпиона по ответам, а шпион может попытаться угадать место. В сообщениях бота — текст, иллюстрации и зацикленные видео с подписями и кнопками.

## Как играть

1. Создайте приватную группу. В личке с ботом нажмите «Добавить в группу» и выберите её. Если набор не открылся, отправьте в группе `/spy`.
2. Создатель проходит проверку. Все игроки, включая создателя, нажимают «Войти в игру» и нажимают «Старт» в личке. Бот обновляет один список участников. Галочка означает, что игрок открыл личку для секретной карточки.
3. Создатель нажимает «Начать игру» в группе. Игроки выбирают карточки в личке. После отсчёта 3 → 2 → 1 бот удаляет секретные сообщения.
4. Отвечайте на подсказки бота прямо в группе либо используйте `/q вопрос` и `/a ответ`. Шпион может открыть список локаций командой `/guess` в личке.
5. Через 5 минут начинается тайное голосование в личке. Создатель может начать его раньше командой `/vote` в группе. Под итогом в группе появится «Новый раунд». При новом раунде бот убирает свои недавние игровые объявления, а переписка игроков остаётся.

## Запуск

Нужен Go 1.23 или новее. Внешних библиотек нет, медиа встроены в исполняемый файл.

```sh
go test ./...
go build -trimpath -o truespy .
```

Передайте токен от BotFather через переменную окружения `BOT_TOKEN`. Затем выполните:

```sh
./truespy --check   # проверяет токен без получения обновлений
./truespy           # запускает игру
```

Состояние игры хранится в `data/rooms.json`. Путь можно изменить через `SPY_STATE`. Запускайте только один процесс на токен.

## Linux VPS с systemd

Установите собранный под архитектуру сервера файл как `/opt/truespy/truespy`. Создайте `/etc/truespy.env` с правами `0600` и строкой `BOT_TOKEN=...`. Скопируйте `deploy/truespy.service` в `/etc/systemd/system/` и выполните:

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now truespy
sudo systemctl status truespy
sudo journalctl -u truespy -n 50
```

Сервис запускается без прав root, перезапускается после сбоя и хранит комнаты в `/var/lib/truespy`. Токен и состояние игры не нужно добавлять в Git.
